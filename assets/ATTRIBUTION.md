# Third-party assets

The game uses the following third-party assets. Their original licenses are kept in
`assets/licenses/`.

## Alternate Space Invaders sprite sheet

- **File:** `assets/sprites/alternate_space_invaders.png`
- **Author:** WaffleKilometer
- **Source:** <https://opengameart.org/content/alternate-space-invaders>
- **License:** [CC0 1.0](licenses/CC0-1.0.txt)
- **Changes:** The original sheet is used directly. Individual source rectangles are
  selected at runtime for the player, invaders, projectiles, bunkers, and explosions.
- **Notes:** Attribution is not required. The original author explicitly placed the
  graphics in the public domain.

## Press Start 2P

- **File:** `assets/fonts/PressStart2P-Regular.ttf`
- **Designer:** CodeMan38
- **Source:** <https://fonts.google.com/specimen/Press+Start+2P>
- **License:** [SIL Open Font License 1.1](licenses/PressStart2P-OFL.txt)

## 8-Bit Sound Effect Pack (Vol. 001)

- **Files:** `assets/sounds/*.wav`
- **Author:** Deva / Shades
- **Source:** <https://opengameart.org/content/8-bit-sound-effect-pack-vol-001>
- **License:** [CC0 1.0](licenses/CC0-1.0.txt)
- **Selected sounds:** Shoot 1, Shoot 2, Explosion 2, Hit 2, Powerup 1, and Exit 3
- **Changes:** Files were renamed for their in-game roles; audio content was not changed.
- **Notes:** Attribution is not required, although the source pack asks that the author
  be credited where possible.
